# MongoDB Atlas setup — step-by-step

You need a free MongoDB Atlas cluster and a connection string. Takes about 5
minutes.

## 1. Create an account
1. Go to https://www.mongodb.com/cloud/atlas/register
2. Sign up (Google sign-in is fine).

## 2. Create a free cluster
1. Once logged in, Atlas prompts you to create a project. Name it
   **WINterview** (or anything).
2. Click **+ Create** (or **Build a Database**).
3. Pick the **Free / M0 / Shared** tier.
4. Provider + region: AWS is fine; pick a region near you.
5. Cluster name: `winterview` (default `Cluster0` is also fine).
6. Click **Create Deployment**. Provisioning takes ~1–3 minutes.

## 3. Create a database user
Atlas will pop up a **Security Quickstart** panel. If it doesn't, go to
**Security → Database Access** in the left nav.

1. Username: `winterview`
2. Password: click **Autogenerate Secure Password** and **copy it now** — you
   won't see it again. Save it somewhere safe.
3. Built-in role: **Read and write to any database** (or **Atlas admin** for
   the dev project).
4. Click **Create User**.

## 4. Allow your IP to connect
Still in the Security Quickstart (or **Security → Network Access**):

1. Click **Add IP Address**.
2. Choose **Add Current IP Address** for local dev.
3. Optional (only if you're on flaky wifi / multiple machines): choose **Allow
   Access from Anywhere** (`0.0.0.0/0`). It's fine for dev but don't do this in
   production.
4. Click **Confirm**.

## 5. Get your connection string
1. Go to **Database → Clusters** in the left nav.
2. On your cluster, click **Connect**.
3. Choose **Drivers** (not Compass, not Shell).
4. Driver: **Python**, Version: **3.12 or later** (any recent one is fine).
5. Copy the URI. It looks like:
   ```
   mongodb+srv://winterview:<db_password>@winterview.abcde.mongodb.net/?retryWrites=true&w=majority&appName=winterview
   ```
6. **Replace `<db_password>`** with the password you saved in step 3.
   URL-encode any special characters in the password (e.g. `@` → `%40`,
   `#` → `%23`). If you used the autogenerated password from Atlas it's
   alphanumeric, so no encoding needed.

## 6. Paste it into `.env`
Open the repo-root `.env` and paste the URI:
```
MONGO_URI=mongodb+srv://winterview:YOUR_PASSWORD_HERE@winterview.abcde.mongodb.net/?retryWrites=true&w=majority&appName=winterview
MONGO_DB=winterview
```

## 7. Seed the 50 preset questions
From the repo root:
```sh
cd backend
uv sync
uv run python scripts/seed.py
```
Expected output:
```
Inserted 50 new questions. Total: 50
```

## 8. Verify in Atlas
- Go to **Database → Clusters → Browse Collections**.
- You should see a database `winterview` with a `questions` collection
  containing 50 documents. The other collections (`users`, `sessions`,
  `responses`, `comments`, `ratings`, `reactions`) get created automatically
  on first write.

## Troubleshooting

**`ServerSelectionTimeoutError` / can't connect**
- Your IP isn't allow-listed (Security → Network Access). Add your current IP.
- You're on a VPN that blocks outbound 27017. Try toggling the VPN off.

**`Authentication failed`**
- Password in the URI is wrong or not URL-encoded.
- You created the user in a different project. Users are per-project.

**`MONGO_URI is not set`**
- The backend reads `.env` from the **repo root**. Make sure you're editing
  `WINterview/.env`, not `WINterview/backend/.env`.

**Seed script inserted 0 questions**
- That means they were already seeded. `seed.py` is idempotent.
